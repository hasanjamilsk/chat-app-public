# চ্যাট অ্যাপ

নাম্বার + পাসওয়ার্ডে লগইন, প্রত্যেকের ইউনিক কোড, কোড দিয়ে বন্ধু যোগ, টেক্সট মেসেজ ও ইমোজি।

## ফোল্ডারের গঠন

```
server.js                 সার্ভার ও ডাটাবেস
package.json              Node.js ২২+ লাগবে
render.yaml               Render-এ হোস্ট করার কনফিগ
.node-version             Node ভার্সন
public/
  index.html              অ্যাপের পেজ
  manifest.webmanifest    ফোনে অ্যাপ হিসেবে ইনস্টলের তথ্য
  sw.js                   সার্ভিস ওয়ার্কার
  icon-192.png, icon-512.png   অ্যাপের আইকন
```

## কম্পিউটারে চালানো (টেস্টের জন্য)

`node server.js` চালিয়ে http://localhost:3000 খোলো। কোনো প্যাকেজ ইনস্টল লাগে না।

## অনলাইনে হোস্ট করা (Render)

1. ফাইলগুলো একটা GitHub রিপোজিটরিতে তোলো (`data.db` তুলবে না, `.gitignore` এ ব্যবস্থা আছে)।
2. Render এ New → Blueprint বেছে রিপোজিটরিটা দাও। `render.yaml` পড়ে নিজে সব সেট করবে।
3. ডিপ্লয় শেষ হলে একটা `https://...onrender.com` লিংক পাবে। সেটাই তোমার অ্যাপ।

### ডাটা স্থায়ী রাখা নিয়ে সতর্কতা

অ্যাকাউন্ট আর মেসেজ `DATA_DIR` ফোল্ডারে থাকে। Render এ এই ফোল্ডার স্থায়ী রাখতে ডিস্ক লাগে, যা শুধু পেইড প্ল্যানে (starter) পাওয়া যায়। ফ্রি প্ল্যানে চালালে সার্ভার রিস্টার্ট বা নতুন ডিপ্লয়ের সময় সব ডাটা মুছে যায়। শুধু টেস্টের জন্য ফ্রি চলবে।

## এখন যা আছে

- নাম্বার + পাসওয়ার্ডে রেজিস্টার ও লগইন (পাসওয়ার্ড হ্যাশ করে রাখা হয়), সেশন ৩০ দিনের
- ভুল পাসওয়ার্ড বারবার দিলে ১০ মিনিটের জন্য আটকে দেওয়া
- প্রত্যেকের ইউনিক কোড, কোড দিয়ে যোগ করলে দুজনের লিস্টেই একে অপরকে দেখা যায়
- টেক্সট মেসেজ, ইমোজি, না-পড়া মেসেজের সংখ্যা
- ফোনে "হোম স্ক্রিনে যোগ করো" দিয়ে অ্যাপের মতো ইনস্টল করা যায়
